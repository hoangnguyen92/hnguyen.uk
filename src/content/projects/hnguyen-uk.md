## Why I built it

I wanted one place for my interview prep notes and side projects that I can update in a
couple of minutes.

## How it works

- Every page is a Markdown file in `src/content/`.
- Pushing to GitHub triggers a build on Cloudflare Pages, and the site is live about a minute later.
- Code is highlighted at build time, and system design diagrams are written as Mermaid.
